# Refi – die Methode von Refim

Öffentliche Methode, mit der Refi arbeitet: Agent-Datei, Skills je Sitzungsart
(Kennenlernen, Erster Blick, Retro, Co-Design, Check-in), Vorlagen für den Record
und die Transport-Konventionen für Gespräche in Refim.

Die Refim-App lädt die jeweils neueste Release und übergibt sie der KI-CLI des
Nutzers. Methode und App werden unabhängig voneinander aktualisiert.

Stand: leer – wird in Meilenstein M0 aus `refim-workspace/refim-agent` aufgebaut.
Siehe `ReflectAndImprove_Refim/docs/ARCHITECTURE.md`.
